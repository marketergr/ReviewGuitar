This free guitar string tension calculator turns string gauge, scale length, and tuning into pounds of tension per string. Tension equals unit weight times the square of twice the scale length times frequency, divided by 386.4 — using D'Addario's published unit weights for electric (nickel-wound) strings. Use it to compare a 9–42 versus 10–46 set, or to check tension before dropping to Drop C or Drop D.
